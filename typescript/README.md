# @synadia-ai/agent-fabric

The SDK for agents on the Synadia Agent Fabric, for TypeScript. Tracing
today, built on the hooks of the Synadia Agent Protocol SDK
(`@synadia-ai/agents`, `@synadia-ai/agent-service`). See the repository's
[README](https://github.com/synadia-ai/agent-fabric-sdk#readme) for usage.
