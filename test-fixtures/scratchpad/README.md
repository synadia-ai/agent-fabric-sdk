# ScratchPad native-client fixtures

`codec/` is copied byte for byte from `synadia-ai/scratchpad` at
`2f59c514c9d8aed39b510eae1abbab8062185ed5`, `fixtures/codec/`.
The 47 JSON files and `manifest.txt` define canonical bytes, content identities,
and rejection reasons for ADR-0004. These fixtures contain public format data.
They contain no service implementation, credentials, or deployment settings.

The TypeScript fixture runner verifies every file listed in the manifest.
It also checks that no extra fixture exists. Python can use the same vectors.
For a fixture with an invalid UTF-8 logical name, the TypeScript encoder input
uses an unpaired surrogate: JavaScript cannot represent invalid UTF-8 bytes in
a string. Encoded CBOR fixtures retain their original bytes.

`reference-v2.json` is generated by `generate-reference.go` with the Go client
at the same commit. It pins the actual token and JSON for HTML punctuation,
U+2028, and U+2029. Its ACME account key comes from this repository's public
identity fixtures. Run the generator from that ScratchPad checkout and write
its standard output to `reference-v2.json`.
